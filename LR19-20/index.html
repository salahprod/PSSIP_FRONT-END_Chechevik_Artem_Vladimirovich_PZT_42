      Задание 2. Работа с Cookie

      Заполните форму личных данных → данные сохранятся в Cookie клиента на 7 дней. Чтение и очистка — отдельными кнопками. Результат появится на странице и в консоли.

      Форма личных данных document.cookie

      Cookie — это небольшие текстовые файлы, хранящиеся в браузере. Ограничение объёма — примерно 4 КБ на один домен.

      Результат появится здесь...
      Откройте DevTools → Application → Cookies, чтобы увидеть сохранённые данные.

      Задание 3. Работа с Local Storage

      Та же форма личных данных, но данные сохраняются в постоянное хранилище браузера (Local Storage). Оно не имеет срока давности — данные хранятся до явного удаления.

      Форма личных данных localStorage

      Local Storage хранит данные в виде пар «ключ → значение» без срока давности. Объём — обычно 5–10 МБ на домен.

      Результат появится здесь...
      Откройте DevTools → Application → Local Storage, чтобы увидеть сохранённые данные.
